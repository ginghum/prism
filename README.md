# PRISM — Idol Management

11人のアイドルを育成し、ライブ収益とグッズ販売でチームを成長させるブラウザゲーム。

## 遊び方

- メンバーカードをタップして会話、↗でプロフィールを開きます。
- ライブの応援で資金を獲得し、特訓でメンバーをレベルアップ。
- グッズを仕入れると自動販売。自動入荷も設定できます。
- 2分ごとにフィーバーが発動し、メンバー固有のスキルが活躍します。
- レベル30・50で特別な成長イベントがあります。
- 10秒ごとに自動保存。セーブJSONの書き出し・読み込みで端末間の引き継ぎが可能。
- 画面を閉じている間も、最大8時間分の通常ライブ収益を獲得（グッズ・アイテムは対象外）。

## 公開

GitHub Pages: main ブランチの / (root) を指定。
ビルド不要。画像とCSSを含め、外部CDNへの依存はありません。

## 構成

- index.html: ゲーム画面
- game.js: 元版のプロフィール・台詞・固有スキルとゲーム処理
- enhancements.js: 自動保存、データ引き継ぎ、放置収益、応援、検索
- assets/: 新規立ち絵11枚（WebP）、スタイル、アイコン

元データ: ユーザー提供 prism (7).html。キャラクター設定・画像: ユーザー制作PRISM。
